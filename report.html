1. Executive Summary

This report presents the complete zero-shot phishing classification results across 200 threat samples (100 legitimate URLs and 100 malicious phishing URLs). Following API quota exhaustion in early testing, an auto-pilot evaluation system (auto_eval.py) was developed with automatic state resumption, 503 exponential backoff, rate-limit pacing, and dynamic model failover to achieve 100% completion with zero data loss.

Security Insight & Qualitative Findings
  • High Threat Precision (92%): When the model flags a URL as phishing, it is correct 92% of the time, keeping false alarms on legitimate enterprise traffic low.
  • Cloud Infrastructure Abuse: Successfully detected sophisticated phishing kits masquerading on free hosting platforms (e.g. *.vercel.app, *.pages.dev, *.webflow.io, *.r2.dev).
  • Abused Authoritative Domains: The 13 false negatives consisted almost exclusively of legitimate cloud-service URLs (such as Google Slides and Forms links) that hosted malicious credential-harvesting lures. Zero-shot domain analysis cannot inspect internal presentation contents without deeper page crawling.

4. Engineering & Auto-Pilot Implementation

Component Mechanic & Implementation Benefit
Data Sanitization Purged 190 error rows (predicted_label = -1) caused by prior unpaced quota failure. Restored dataset integrity to 10 verified valid samples.
State Resumption Counts valid completed rows and slices dataset (dataset_df.iloc[start_idx:]). Allows flawless stopping and resuming without re-evaluating completed samples.
Atomic Persistence Each successful sample is appended directly to evaluated_results.csv (mode='a'). Zero progress lost if execution is interrupted or network drops.
503 Backoff Engine Catches server demand spikes and applies exponential delays (3s, 6s, 12s, 24s). Survived temporary Google server overload spikes automatically.
Dynamic Failover Fails over from gemini-3.8-flash (20 RPD cap) to gemini-3.1-flash-lite (1,500 RPD). Allowed full dataset completion in under 15 minutes without waiting 16 hours.
Socket Recovery Catches Windows WinError 10060 and transient TCP disconnects with auto-retry. Eliminated random process termination from internet hiccups.
