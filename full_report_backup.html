This project evaluates the effectiveness of Google's Gemini family of Large Language Models (LLMs) in detecting phishing URLs using a zero-shot classification approach — meaning the model receives no training examples and must classify each URL based solely on its pre-trained world knowledge and a structured system prompt.

Across 200 balanced samples (100 safe + 100 phishing), the model achieved an overall accuracy of 89.5% with a phishing precision of 91.58% and recall of 87.00%. False negatives were heavily concentrated on phishing URLs hosted on authoritative Google services (Slides, Forms, Drawings), highlighting a fundamental limitation of domain-only analysis in zero-shot settings.

2. Problem Statement & Objectives

Problem: Traditional phishing detection relies on blacklists, rule-based heuristics, or supervised ML models trained on labeled feature vectors. These approaches struggle with zero-day phishing campaigns hosted on legitimate cloud infrastructure (e.g., Google Docs, Cloudflare Pages, Vercel). Can a pre-trained LLM classify phishing URLs without any prior training data?

Objectives:

  1. Evaluate zero-shot phishing URL classification performance of Gemini LLMs.
  2. Quantify precision, recall, F1-score, and confusion matrix metrics.
  3. Analyze failure modes (false positives and false negatives) qualitatively.
  4. Identify the fundamental limitations of URL-only zero-shot classification.
  5. Provide actionable recommendations for future hybrid detection systems.

3c. Evaluation Pipeline Architecture

The evaluation was powered by auto_eval.py, a custom automated evaluation script with the following production-grade safeguards:

FeatureImplementation
State ResumptionCounts existing valid rows in evaluated_results.csv and resumes from the next unprocessed row.
Atomic PersistenceEach result is appended to disk immediately after successful classification (mode='a').
503 BackoffExponential backoff (3s → 6s → 12s → 24s → 48s) on server high-demand errors.
429 RPM HandlingDetects per-minute rate limits and waits 20–60s before retrying.
Daily Quota FailoverAuto-switches from gemini-3.8-flash (20 RPD cap) to gemini-3.1-flash-lite (1,500 RPD).
Network RecoveryCatches socket timeouts (WinError 10060) with exponential retry instead of halting.
Zero Error RowsNever writes predicted_label = -1; halts gracefully on unrecoverable errors.

6. Key Findings & Observations

Finding 1: Strong Baseline for Zero-Shot Detection

At 89.5% accuracy, the Gemini LLM demonstrates that pre-trained language models possess substantial knowledge about phishing URL patterns — typosquatting, suspicious TLDs, free-hosting abuse, randomized subdomains — without any task-specific fine-tuning.

Finding 2: Authoritative Domain Blind Spot

The model's primary weakness (61.5% of false negatives) is its inability to flag phishing content hosted on authoritative domains like docs.google.com and zoom.us. This is a fundamental limitation of URL-only zero-shot classification — the model trusts the domain reputation without being able to inspect the actual page content.

Finding 3: High Phishing Precision (91.6%)

When the model flags a URL as phishing, it is correct 91.6% of the time. This is valuable for automated triage pipelines where false positives are costly (e.g., blocking legitimate business URLs).

Finding 4: Free-Tier Hosting Kits Successfully Detected

The model accurately detected phishing campaigns across a wide variety of free hosting platforms: *.vercel.app, *.pages.dev, *.webflow.io, *.netlify.app, *.weebly.com, *.gitbook.io, *.r2.dev. This reflects strong generalization across modern phishing infrastructure.

Finding 5: Prompt-Driven Reasoning Quality

Each classification included a 1-sentence cybersecurity justification, providing interpretable reasoning that traditional ML classifiers cannot offer. This explainability is crucial for SOC analyst workflows and regulatory compliance.

To strengthen the paper, your teammate should consider running these comparative experiments:

  1. Few-Shot Comparison: Re-run the evaluation with 3–5 labeled examples in the prompt (few-shot) and compare accuracy vs. zero-shot to quantify the impact of in-context learning.
